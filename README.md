### 🔧 What I Do

- ☁️ Provision cloud infrastructure on **AWS** (EC2, VPC, Security Groups, IAM, S3, Route 53, Auto Scaling, ELB) using **Terraform** with modular, reusable code and remote state management
- ⚙️ Automate server and application configuration with **Ansible** — playbooks, roles, dynamic inventory, and Vault for secure credential management
- 🐳 Containerize applications with **Docker** — multi-stage builds, minimal base images, and non-root user configuration for smaller, more secure images
- ☸️ Orchestrate workloads on **Kubernetes** — Deployments, Services, Ingress, ConfigMaps, HPA, Helm charts, RBAC, and rolling/blue-green deployments
- 🚀 Build **CI/CD pipelines** with **Jenkins** (declarative syntax, Shared Libraries) and **GitHub Actions**, enforcing quality gates with SonarQube and image scanning
- 📈 Set up **monitoring and alerting** with CloudWatch, Prometheus, and Grafana, building custom dashboards for proactive incident detection
- 🤖 Automate operational tasks using **Linux**, **Bash**, and **Python** scripting

### 🌟 Featured Project

**Microservices E-Commerce Platform** | *End-to-End DevOps Deployment on AWS*

Designed and deployed a 3-tier, microservices-based e-commerce application with independently scaled frontend, backend, and database services, simulating a production-style architecture. Provisioned AWS infrastructure manually first, then fully automated with Terraform; automated configuration with Ansible; containerized every microservice with Docker; orchestrated on Kubernetes with Helm, HPA, and RBAC; built CI/CD pipelines in Jenkins and GitHub Actions with SonarQube quality gates; and set up monitoring with CloudWatch, Prometheus, and Grafana.
